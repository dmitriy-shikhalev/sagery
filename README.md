# sagery

## Сценарии использования:
- Создание Саги
- Создание Оператора в Саге
- Создание Очереди в Саге
- Изменение Инпутов и Аутпутов (связка с Очередью) в Операторе в Саге
- Создание Джобы
- Создание Велью в Роу Джобы
- Проверка статуса Джобы
- Получение списка Велью из Роу Джобы
- Проверка статуса Ланча Джобы
- Получение статуса Роу Джобы

## Внутренние процессы:
- Процесс конкретной джобы (корутина). Здесь будет и распространение ошибки вверх,
и распространение аборта вниз, и здесь же установка завершенности Очереди, если
Ланчи-родители завершены. И установка того, что Ланч завершен, если входящие Очереди
завершены и сам Ланч завис на фазе получения нового элемента.
- Процесс конкретного ланча, если Ланч упал с ошибкой и успешно завершен, то Ланч становится тоже завешен.
- Процесс запуска операторов (асинхронных)

Количество корутин джоб и корутин ланчей должно иметь лимит. То есть должен быть пул корутин.
По типу простого глобально счетчика.
