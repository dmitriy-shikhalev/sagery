# sagery

## Кейс 1: 
`$ sagery op sum 1 2` должно вернуть `3` - это вызов оператора, а не джобы.

## Кейс 2:
`$ sagery saga sum_saga 1 2` должно вернуть тоже `3`, но это уже будет результат работы джобы, а не оператора.

- А как тогда передать несколько наборов аргументов в одну джобу с этим интерфейсом?
- Разделить наполнение аргументов и создание джобы?
- Возврат к старой концепции: джобы отдельно, инпуты отдельно; всё взаимодействие происходит по API.
- Ближайшая задача: добавить модели и алембик с очисткой и накаткой на тестах.
